# 번들 아이콘

⚠️ **파일 이름이 `README.md`가 아닌 이유** — `App/`은 Xcode 동기화 루트 그룹이라 하위 폴더가
번들 루트로 **평탄화된다.** `App/Fonts/README.md`가 이미 그 자리를 쓰고 있어 같은 이름을 두면
*"Multiple commands produce …/README.md"* 로 빌드가 깨진다(2026-08-12 실측).

**시스템 심볼을 쓰지 않는다.** 앱 크롬의 글리프는 전부 [lucide](https://lucide.dev)에서 오고
`Icons.xcassets`에 벡터로 실린다. 이름 목록은 코드의 `Glyph`가 갖는다.

## 왜 갈아탔나

`square.and.pencil`이 **iOS 메일·메모의 「새로 쓰기」 아이콘**이라, 일기장 앱의 주요 액션에
그것이 앉아 있는 것이 이 제품의 얼굴을 시스템 크롬으로 만들었다. 후보를 실물에 깔아
판정했고(2026-08-12), 갈아타는 비용이 가장 쌀 때가 지금이라는 것이 함께 근거가 됐다 —
**그때 앱이 쓰는 글리프가 여덟 개였고** 캔버스 도구가 붙으면 스무 개대로 간다.

⚠️ **부분 도입은 금지다.** 한 캡슐 안에 두 계열이 섞이면 어느 쪽 단독보다 나쁘다.
새 글리프가 필요하면 lucide에서 찾는다 — 없다고 SF Symbol을 섞지 마라.

## 실측 — 갈아타며 확인한 것 (2026-08-12)

| | |
|---|---|
| 획 굵기 | **lucide가 SF보다 얇다.** 유리 캡슐에 20pt로 올려 재확인했다 |
| ⚠️ 다크 + 유리 | 가는 획이 어두운 유리 위에서 존재감을 잃는 쪽이 진짜 위험이다 |
| ⚠️ 광학 정합 | **글리프마다 상자를 채우는 비율이 다르다.** 대각선(깃펜)은 꽉 차고 원(톱니바퀴)은 덜 찬다 — SF Symbols가 공짜로 해주던 정규화를 이제 사람이 본다 |

## ⚠️ 글리프만 있는 버튼에는 접근성 라벨이 의무다

**시스템 심볼은 낭독 이름을 유추해 준다. 자산 이미지는 안 해준다.** 갈아타면서 `06` 닫기와
`09` 더보기가 조용히 이름을 잃었고, 커밋 전 리뷰가 잡았다(2026-08-12).

**글리프가 유일한 내용인 버튼은 `.accessibilityLabel`을 단다.** 옆에 글자가 서 있거나
(`09-G2 ＋ 사진 더하기`) 부모가 탭을 지는 자리(`10` 타일 위 배지)는 그 이름이 이미 있으므로
예외다. 이름은 `Wording`이 갖는다 — **화면에 안 보이지만 문자열이다.**

## 라이선스

**ISC.** Feather에서 유래한 부분은 MIT다. 둘 다 재배포를 허용하고 **의무는 저작권 고지 동봉
하나** — `LICENSE-lucide.txt`가 그 사본이고, 서체의 `OFL/`과 같은 이유로 번들에 함께 실린다
(의무는 저장소가 아니라 **배포물**에 걸린다).

## 고르는 곳과 싣는 곳이 다르다

**pen에서 고르고, upstream에서 싣는다.** 후보를 나란히 놓고 판정하는 데는 pen이 좋고
(`docs/design-system.pen`에 라이브러리 넷을 깐 탐색 프레임이 있다), **번들에 들어가는 파일은
lucide 원본이어야 한다.**

⚠️ **pen 내보내기를 소스로 쓰면 안 되는 이유 둘** (2026-08-12 실측) —

| | |
|---|---|
| **디자인 그리드가 사라진다** | pen은 잉크 경계로 잘라내므로 24×24 안의 여백이 버려진다. 그러면 글리프마다 상자를 채우는 비율이 달라져 **`ellipsis`는 꽉 차고 `chevron-left`는 작게 읽힌다** |
| **획이 아니라 채워진 윤곽선이다** | 아이콘 폰트 글리프를 아웃라인으로 변환한 것이라 `stroke-width`가 없다 — 굵기를 못 만진다 |

⚠️ **pen의 PDF 내보내기는 아예 비어 있다**(알파 0 사각형만). SVG가 나오는 경로는
`export_html` 하나고, 그것도 위 이유로 판정용이지 소스가 아니다.

## 아이콘을 더할 때

1. `docs/design-system.pen`에서 후보를 나란히 깔아 고른다 — `icon` 노드 · `library: "lucide"`
2. 고른 이름의 원본을 받는다 —
   `https://raw.githubusercontent.com/lucide-icons/lucide/main/icons/<이름>.svg`
3. `stroke-width`를 **2 → 2.25**로 바꿔 `Icons.xcassets/<이름>.imageset/`에 넣는다.
   `Contents.json`은 옆 imageset을 복사하되 **`preserves-vector-representation`과
   `template-rendering-intent: template`을 반드시 켠다**
4. `Glyph`에 이름을 더한다

★ **획 굵기 2.25는 이 앱의 값이다.** lucide 기본값 2가 SF Symbols보다 얇아, 어두운 유리 위에서
존재감을 잃는 것을 한 눈금 갚은 것이다. **여덟 개가 같은 값을 써야 한다** — 하나만 다르면
같은 캡슐 안에서 무게가 갈린다.
