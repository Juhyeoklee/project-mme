# 번들 서체

세 자리에 각각 한 벌씩이다. 고른 근거와 자리별 조건은 디자인 토큰 문서 §12(워크스페이스)에 있다.

| 자리 | 서체 | 굵기 | 라이선스 |
|---|---|---|---|
| 앱 UI 본문 | IBM Plex Sans KR | Regular · SemiBold · Bold | SIL OFL 1.1 — **RFN `"Plex"`** |
| UI 액센트 | 푸어스토리 (Poor Story) | Regular | SIL OFL 1.1 |
| 캔버스 본문 | 고운바탕 (Gowun Batang) | Regular · Bold | SIL OFL 1.1 |

## 라이선스

**셋 다 SIL Open Font License 1.1이다.** 번들 동봉 · 공개 저장소 재배포 · 웹폰트 임베딩이 §2에서
명시적으로 허용되고, **의무는 라이선스 사본 동봉 하나**다 — `OFL/`에 서체별 원본 사본이 있다.

⚠️ **IBM Plex Sans KR에는 예약 이름(`"Plex"`)이 있다.** 그대로 번들하는 것은 문제없지만
**서브셋은 OFL에서 「수정」이라 예약 이름을 쓸 수 없다** — 웹 자산용으로 쪼갤 때 이름을 바꿔야 한다.

## 적재와 번들

**런타임 등록이다** — `Typography.register()`가 여섯 벌을 프로세스에 올린다. 이 프로젝트는
`GENERATE_INFOPLIST_FILE`을 쓰므로 `UIAppFonts` 배열을 넣을 자리가 없다.

⚠️ **`App/`은 Xcode 동기화 루트 그룹이라 예외 목록이 없다.** 이 폴더는 통째로 타깃 리소스가
되고, **모든 빌드의 앱 번들에 약 28MB가 실린다**(2026-08-14 실측). 커밋 전 리뷰가 잡은
자리다(2026-08-07).

**의도한 배치다.** **폰트가 번들에 실리면 `OFL.txt`도 함께 실려야 맞다** — OFL §2의 의무는
저장소가 아니라 **배포물**에 걸린다. 밖으로 빼면 타깃 멤버십을 다시 붙여야 하고 이 이행도
헐거워진다.
