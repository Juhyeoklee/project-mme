# 주석 규칙

**주석은 선언을 설명하는 자리다** — 모듈·타입·함수·변수가 무엇이고 무엇을 보장하는가.
**로직을 한국어로 옮기지 않는다.** 코드가 이미 말하는 것은 다시 말하지 않는다.
예외는 하나 — **되돌리면 깨지는 자리(지뢰)** 는 본문에 적는다.

## 어디에 무엇을 쓰는가

| 자리 | 쓴다 | 분량 |
|---|---|---|
| **모듈·타입 `///`** | 이것이 무엇이고 **무엇을 보장하는가** — 공개 계약 · 불변식 · 잘못 쓰는 법 | 필요한 만큼. **여기는 두터워도 된다** |
| **함수·변수 `///`** | 시그니처가 못 담는 것 — 계약 · 단위 · 근거 있는 값의 출처 | **1~2줄.** 계약을 지는 함수는 예외 ↓ |
| **파일 머리 `//`** | 이 파일이 무엇인지 + 파일 전체에 걸리는 계약 | **5줄 이내** |
| **본문 `//`** | **지뢰만** — 되돌리면 깨지는 것 · 플랫폼이 문서와 다르게 구는 것 · 결정성이 걸린 것 | **1~2줄.** `⚠️`로 연다 |

**모듈 문서가 얇은 것도 위반이다.** 총량을 줄이라는 말은 타입 문서를 줄이라는 뜻이 아니다 —
파일 머리에 있던 계약은 타입 위 `///`로 올린다(Quick Help에 뜬다).

### 예외 하나 — 계약을 지는 선언은 타입 문서와 같은 층이다

**문법상 함수·변수지만 하는 일이 「모듈·타입」인 자리가 실재한다.** 자격은 셋뿐이다.
**아래는 등재부가 아니라 판별식이다** — 오른쪽은 자격을 알아보기 위한 보기고,
새로 해당하는 선언이 생겨도 이 표를 고치지 않는다.

| 자격 | 알아보기 위한 보기 |
|---|---|
| **모듈의 입구** — 그 함수가 곧 공개 계약 표면이다 | `Classifier.classify` — 부분 입력 계약 · 전량 열거 전제 |
| **다른 언어 구현이 재현해야 하는 것** | `averageLinkageClusters` — 갱신식 · 병합 순서 · 동률 처리 |
| **리스크가 사는 자리** | `AlbumPhotoSource.image` — `R8` |

⚠️ **셋 중 하나라고 말할 수 있을 때만이다.** *"중요해서"* 는 자격이 아니다 — 그 말은 모든
선언에 붙는다. 해당하지 않는데 넘칠 것 같으면 **지뢰를 본문 `//`로 내린다**(그 자리가 이미 있다).

## 쓰지 않는 것

1. **로직 설명** — *"목록 폭을 재서 스트립에 넘긴다"* · *"인셋을 주면 띠로 보인다"*
2. ★ **설계 의사결정과 그 근거** — *"강조색이 들어갈 자리가 없다"* · *"층위가 사라진다"* ·
   *"미배정 자리의 배정이다"*. **화면설계서·토큰·`PRD`의 몫이다**
3. **이름이 이미 말하는 것** · **쓰이는 자리 나열**(`04-N2 · 04-B2 · 05-N3 …`) — grep이 더 정확하다
4. **경위와 이력** — git이 말한다

## 참조는 「안 죽는 층」만 가리킨다

**코드보다 수명이 긴 문서만 가리킨다.** 화면설계서·토큰은 마일스톤마다 개정·재작성되므로
코드보다 수명이 짧다 — 가리키면 문서가 움직일 때 코드가 조용히 낡는다.
(`M1` 실측: ADR·요구 ID·커밋 참조는 **0건** 낡았고, 산출물 문서 `§` 참조는 **39건**이 한꺼번에 낡았다.)

| 가리켜도 되는 것 | 가리키지 않는 것 |
|---|---|
| ADR 번호 + 결정/대가 번호 (`` ADR `0004` 결정 2 ``) | **화면설계서 `§`** · **디자인 토큰 `§`** |
| 요구(`MOM-01`) · 원칙(`P5`) · 리스크(`R8`) · 화면(`04-C3`) | 총칭 이름(*설계서* · *토큰*) — 문서가 둘이 되면 안 풀린다 |
| 커밋 해시 · 실험 문서 §(고쳐 쓰지 않는 기록) | 판정 **서사 자체** — 그건 참조가 아니라 복사다 |

**화면 ID는 리터럴에 다른 신원이 없을 때만 단다** — `Wording`의 문자열, `Tokens`·`ImageStore`의
숫자처럼. **화면 코드에는 안 단다**(파일이 곧 화면이다). **둘 이상이면 나열하지 말고 뺀다.**

값의 근거가 산출물 문서에만 있으면 **`§` 대신 값과 이유를 한 줄로 적는다** —
*"34%는 iPhone과 같은 3장/행이 나오는 값이라 어림수가 아니다."*

## 그 밖

1. **근거 있는 값에는 출처를 단다** — 실측치 · 실험 § · 날짜
2. **관측 주장에는 날짜를 단다** — *"검증 기기에 실제로 있었다(2026-08-03)"*
3. **갈림에는 안전한 실패 방향을 적는다** — *"안 나누는 쪽이 안전한 실패 방향이다"*
4. **미래 변경 지점에 전언을 남긴다** — *"부분 배열을 넘기는 경로를 만들지 마라"*
5. **테스트 이름은 한국어 서술문이다** — 테스트가 곧 명세 문장. `판정_단위가_인접쌍이_아니라_군집이다`
6. **문체** — 한국어 단정형 문어체, 식별자는 영문, 강조는 `**볼드**`, ID·심볼·파일명은 백틱

## 기계로 보는 셋

`precommit-review` 2단계가 돌린다. **아래 알려진 오탐 하나를 빼고 전부 0이어야 한다.**

```
cd apple
grep -rnE '(설계서|토큰) §' --include='*.swift' . | grep -v '/.build/'   # 산출물 문서 참조
grep -rnE 'ADR [0-9]'      --include='*.swift' . | grep -v '/.build/' \
    | grep -v 'scripts/verify-boundaries'   # 백틱 없는 ADR 번호 — 검증기의 출력 문자열은 주석이 아니다 (2026-08-10)
awk '/^ {8,}\/\/($|[^\/])/{n++; next} {if(n>=3) print FILENAME":"FNR; n=0}' \
    $(find . -name '*.swift' -not -path '*/.build/*' -not -path '*Tests*')  # 본문 3줄 연속
```

⚠️ **알려진 오탐 — `scripts/verify-boundaries.swift`의 두 줄.** 둘째 검사가 이 파일을 잡는데
**주석이 아니라 터미널에 찍히는 출력 문자열**이다(`"① 커널은 import 0 (ADR 0001 결정 2)"`).
grep은 주석과 리터럴을 못 가른다. **검사 범위에서 `scripts/`를 빼지 않는다** — 그러면 검증기
안의 진짜 주석 위반을 못 본다. 이 둘 말고 걸리는 것이 있으면 그건 진짜다.

⚠️ **셋째 검사는 `///`를 빼고 본다** — `//`가 `///`의 접두사라, 안 빼면 **중첩 타입의 문서
주석이 전부 걸린다**(2026-08-11 실측). 위 「어디에 무엇을 쓰는가」가 타입 `///`를 명시적으로
허용하므로 그건 검사가 규칙을 어기는 것이다. 세는 대상은 **본문 `//` 세 줄 연속** 하나다.

⚠️ **주석/코드 비율은 안 잰다.** 선언만 있는 파일은 한 줄씩만 붙여도 치솟아 오탐이 된다 —
실측에서 가장 잘 정리된 파일 셋(`Wording` 70% · `Classification` 68% · `Tokens` 60%)이 전부 걸렸다.

## 기계가 목록만 내는 것 하나 — ⚠️ 위 셋과 성격이 다르다

**위 셋은 게이트다(전부 0). 이것은 트리아지다 — 치면 「후보」지 「위반」이 아니다.**
자격 판정(「예외 하나」)은 사람 몫이라 기계가 결론을 못 낸다. **그 자격 판정이 사람 몫이라는
것과, 길이를 기계가 못 잰다는 것은 다른 말이다** — 길이는 잴 수 있다.

```
cd apple
awk '
/^ *\/\/\/($| )/ { if (!b) { b=1; n=0; s=FNR } n++; next }
{ if (b) {
    if (n >= 3 && $0 ~ /(^|[ (])(func|var|let)([ <(])/ \
                && $0 !~ /(^|[ ])(struct|enum|class|actor|protocol|extension)[ :]/)
      print FILENAME":"s"  ("n"줄)"
    b = 0 } }
' $(find . -name '*.swift' -not -path '*/.build/*' -not -path '*Tests*')
```

⚠️ **빈 `///` 줄을 블록의 일부로 센다.** 안 그러면 `///` 하나로 나뉜 5줄짜리가 2+2로 갈려
**빠져나간다** — 처음 쓴 판이 정확히 그렇게 새서 「위반 0」을 냈다(2026-08-13 실측).

**목록을 읽는 법** — 걸린 자리마다 위 「예외 하나」의 자격 셋 중 **하나를 이름으로 댈 수 있는가**를
묻는다. 못 대면 줄이고, 대면 그대로 둔다. *"중요해서"* 는 자격이 아니다.

**도입 시점의 목록은 여덟이었다** (2026-08-13) — 커널 다섯 · 어댑터 셋 · **`App` 0**.
★ **그중 셋이 위 판별식 표가 이미 이름으로 들고 있는 자리다**(`Classifier.classify` ·
`averageLinkageClusters` · `AlbumPhotoSource.image`). **자격을 지는 선언이 실제로 걸린다는 뜻이고,
그래서 이 검사는 게이트가 될 수 없다.**

아니라 *"자가 고장 났다"* 였다는 것이 이 검사를 넣은 마지막 근거다.
