# 0012 — 시스템 사진 피커는 어댑터 패키지 안의 별도 타깃에 산다

> 상태: **확정** · 2026-08-11
> `M2` 구현 1(기록 뼈대). `REC-10`(직접 가져오기)을 구현하려다 열린 자리다.

## 맥락

`REC-10`은 *"사용자가 시스템 사진 피커로 소스 밖 사진을 한 장씩 지목한다"* 이고, 그 판정의 핵심은 **앱이 소스 밖을 훑지 않는다**(`SRC-08`)는 것이다. 피커는 사용자가 고른 것만 앱에 건네므로 라이브러리 접근 권한도 필요 없다.

그런데 구현하려면 `PhotosUI`를 import해야 하고, ADR `0001` 결정 4가 세운 검증기 ②가 **`App` 소스의 사진 프레임워크 직접 import**를 막는다. 즉 지금 구조에서는 피커가 갈 자리가 없다.

**검증기 명단에서 `PhotosUI`만 빼는 안을 실측으로 기각했다** (2026-08-11). 다음이 iOS 26 시뮬레이터 SDK에서 타입 검사를 통과한다.

```swift
import PhotosUI
func probe() {
    _ = PHAsset.self
    _ = PHAssetChangeRequest.self   // 쓰기 심볼
}
```

`PhotosUI`의 ObjC 모듈이 `Photos` 헤더를 가져오므로 **한 줄로 원본 쓰기 API까지 보인다.** 명단을 좁히면 ADR `0001` 근거 2(*"나머지 코드에는 원본을 건드릴 경로가 컴파일 타임에 없다"*)가 기계 강제를 잃는다.

## 결정

**1.** 시스템 피커는 **`PhotoSource` 패키지 안의 새 타깃 `PhotoSourceUI`** 에 산다. 새 패키지를 만들지 않는다.

**2.** `PhotoSourceUI`는 **`PhotoSource`에 의존하지 않는다.** 나가는 값은 바이트와 확장자뿐이고 가져올 계약 타입이 없다.

**3.** `App`의 사진 프레임워크 import는 **여전히 0**이다. 검증기 ②는 손대지 않는다.

**4.** 이 타깃의 공개 표면은 **뷰 수정자 하나와 값 타입 하나**다 — 열거·검색·권한 API를 두지 않는다. 소스를 넓히지 않는다는 것이 표면으로 보여야 한다.

## 근거

**1.** ADR `0001` 결정 2가 *"사진 라이브러리를 아는 모듈은 `PhotoSource` 하나"* 로 못 박았다. **새 패키지를 만들면 그 문장이 깨지고 둘이 된다.** 같은 패키지 안의 타깃이면 경계의 개수가 안 늘고 그 문장이 그대로 산다.

**2.** ★ **검증기 ③(어댑터의 쓰기 심볼 금지)이 `Packages/PhotoSource/Sources`를 통째로 훑으므로 새 타깃에 자동으로 걸린다.** 스크립트를 한 줄도 안 고치고 기계 강제가 새 코드까지 덮는다 — 도구를 안 늘리는 것이 이 프로젝트의 방식이다(ADR `0003` 결정 3).

**3.** `PhotoSource` 코어에 직접 넣지 않은 이유는 **구현체 교체**다(ADR `0001` 결정 5). macOS의 폴더 소스가 올 때 갈아끼우는 것은 *열거와 바이트 읽기*지 피커가 아니다. 코어가 SwiftUI를 물면 그 교체가 UI까지 끌고 온다.

**4.** 결정 2는 결정 1(*이유 없는 간선을 만들지 않는다*)의 적용이다. `PhotoSource`의 `SourceAsset`은 **소스 안** 사진의 손잡이인데, 피커가 주는 것은 소스 밖 바이트라 그 타입을 쓸 자리가 없다.

## 결과와 대가

**얻는 것** — `App`이 사진 프레임워크를 모른다는 사실이 유지되고, 그것을 지키는 장치가 새로 생기지 않는다. 두 경로(*앱이 훑는 것* / *사용자가 건네는 것*)가 코드에서도 갈려 `PRD` §11.7의 판정이 구조로 보인다.

**포기한 것과 대가** —

1. **타깃이 하나 늘어 빌드 그래프가 조금 복잡해진다.** 패키지는 안 늘었지만 링크 대상은 늘었다
2. **가져온 사진에는 `SourceAsset`이 없다.** 기록 안에서 두 출처를 가르는 일이 `App` 몫으로 남는다 — 모델의 `RecordImage.Origin`이 그 자리다
3. **피커가 주는 촬영 정보를 버린다.** `REC-10`의 규칙(*촬영 정보를 읽지 않는다*)을 표면으로 강제한 것이라 의도한 손실이지만, 나중에 그 값이 필요해지면 계약을 넓혀야 한다

**재검토 조건** — 없다. 다른 플랫폼(`M5`)이 자기 피커를 들고 와도 같은 모양(그 플랫폼의 UI 타깃)으로 붙는다.
