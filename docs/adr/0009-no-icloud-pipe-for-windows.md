# 0009 — Windows용 iCloud를 동기화 파이프로 쓰지 않는다

> 상태: **확정** · 결정 2026-07 (`WHY.md` 작성기) · 기록 2026-08-05
> `WHY.md` §5 탈락 표의 ADR 기록이다 — 새 논증이 아니라 이미 적힌 것을 옮겨 닫는다.

## 맥락

주 촬영 환경은 Windows PC와 iPhone/iPad다(§4). PC에서 찍힌 스크린샷이 iPad로
와야 하고, Windows용 iCloud를 깔면 그 파이프가 서버 없이 생기는 것처럼 보인다.

## 결정

**동기화 파이프로 쓰지 않는다.** 기기 간 연계는 자체 서버 경로로 간다.

## 근거

**1. 검증이 불확실하다.** 게임이 만드는 폴더의 파일이 언제 어떤 형태로 넘어오는지를
이 프로젝트가 통제할 수 없는 소프트웨어에 걸어야 한다.

**2. Windows 유저에게 "iCloud 깔고 로그인"은 이탈 지점이다.** 온보딩이 타사
소프트웨어 설치를 요구하는 제품이 된다.

## 잃은 것과 재검토 조건

**잃은 것** — 서버 없이 PC→iPad 파이프를 얻는 길. 다만 공유가 어차피 서버를
요구하므로(§2) 아낄 수 있었던 것이 크지 않다.

**재검토 조건** — 없다. 근거 2는 기술 검증으로 뒤집히지 않는 제품 판단이고,
파이프의 대체물(자체 서버)이 `M4`에서 어차피 선다.
