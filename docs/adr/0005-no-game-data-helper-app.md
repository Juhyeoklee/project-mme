# 0005 — 게임 데이터 헬퍼 앱을 만들지 않는다

> 상태: **확정** · 결정 2026-07 (`WHY.md` 작성기) · 기록 2026-08-05
> `WHY.md` §5 탈락 표의 ADR 기록이다 — 새 논증이 아니라 이미 적힌 것을 옮겨 닫는다.

## 맥락

포트폴리오 프로젝트의 제품을 고르는 자리. 원래 아이디어는 하고 있는 게임의
데이터 헬퍼 앱이었다.

## 결정

**만들지 않는다.** 제품은 게임 스크린샷 정리와 기록(모아노기)으로 간다(`WHY.md` §2).

## 근거

**1. 데이터 확보 비용이 개발 비용을 초과한다.** 노력의 무게중심이 앱이 아니라
데이터에 실리는 제품은, 완성돼야 포트폴리오가 된다는 §1의 전제와 맞지 않는다.

**2. 게임사 API 정책에 프로젝트 수명이 종속된다.** 정책 변경 하나로 제품이 통째로
죽을 수 있는 외부 의존이다.

## 잃은 것과 재검토 조건

**잃은 것** — 원래 하려던 제품. 그 자리는 모아노기가 받았고, 따로 무는 대가는 없다.

**재검토 조건** — 없다. 이 프로젝트 안에서 되살아날 자리가 없는 탈락이다.
