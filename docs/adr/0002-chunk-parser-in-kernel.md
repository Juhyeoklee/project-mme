# 0002 — 청크 파서는 커널에 산다

> 상태: **확정** · 2026-08-03
> `0001`의 모듈 정의를 한 곳 갱신한다 — 커널의 입력 정의. `0001` 본문은 고치지 않는다.

## 맥락

분류 신호는 게임이 PNG `iTXt` 청크에 써넣는 촬영 메타데이터와 파일명의 촬영 시각이다(기획 확정, 2026-08-02). 그 파싱 코드가 어느 모듈에 사는지가 `0001`에 없다.

양쪽 다 정의가 안 맞았다. `0001` 결정 2의 `PhotoSource`는 *"사진 라이브러리를 아는 유일한 모듈"* 인데 **게임 파일 포맷을 아는 것은 그 정의에 없다.** `MomentKernel`은 *"사진 메타값 배열 → 순간 구조"* 인데 **바이트는 그 입력이 아니었다.**

선택지 셋 — (a) `PhotoSource` 안 (b) 새 패키지 (c) `MomentKernel` 안.

## 결정

**파서는 `MomentKernel`에 산다. 파일명 파싱도 같다.** 커널의 입력 정의가 이렇게 갱신된다 —

> **커널 입력: 사진별 (파일명, 파일 바이트). 출력: 날짜·순간·장면 구조(`0001`과 동일).**

- **어댑터의 일은 바이트 공급까지다.** 컨테이너를 찾고, 파일을 열거하고, 바이트를 읽는다. 게임 지식 없음 — `PhotoSource`의 정의는 그대로 유지된다
- **신호 추출(바이트 → 값)과 분류(값 → 순간)는 둘 다 커널 안이다.** 내부에서 층을 나눌지는 구현 몫이다
- `M5`의 웹 자산 구현이 다시 만드는 것은 **`MomentKernel` 하나, 통째로**다. 계약 표면이 *"(파일명, 바이트) → 순간 구조"* 하나로 닫힌다 — `0001` 결정 6이 요구한 답이 이것이다

## 근거

**1. 기획이 이미 경계를 그었다.** 기획 확정 문구는 *"소스 지정은 게임을 모르고, 분류 신호는 첫 게임을 안다"* 다. 게임 지식이 살도록 승인된 층은 분류뿐이고, 분류가 곧 커널이다. (a)는 `PhotoSource`가 게임을 알게 되어 이 문장을 모듈 층위에서 어긴다. (c)는 기획의 개념 경계와 물리 경계가 포개진다.

**2. 결정 6이 (c)에서 자명해진다.** 커널 입력이 바이트까지 내려가면 입력의 *생산 과정*은 "파일을 읽는다"뿐이라 어느 플랫폼·언어에서든 자명하게 재현된다. (a)면 웹 구현이 커널 전부 + 어댑터의 일부(파서)를 재현해야 해 계약이 두 모듈에 걸쳐 찢어진다.

**3. 순수성은 깨지지 않는다.** 파싱은 바이트 → 값의 결정적 함수다. I/O는 어댑터에 남는다. 그리고 실측 — 표본 전량의 `iTXt`가 **비압축**(compflag=0, 2026-08-03 확인)이라 zlib조차 필요 없다. **import 0이 유지된다.**

**4. 결정 5의 "구현체 교체"와 맞물린다.** macOS 폴더 소스가 와도 새 어댑터는 바이트 공급만 한다. 파서를 어댑터에 두면 어댑터마다 파서가 복제되거나 결국 공유할 집을 다시 찾게 된다 — 지금 그 집을 잘못 정하는 것이다.

**5. (b)는 결정 1을 통과하지 못한다.** 파서에 걸리는 제약(순수 · 플랫폼 불변 · 타 언어 재현)이 커널의 제약과 완전히 같다 — 같은 제약을 받는 코드를 가르는 구조적 사실이 없다. 그리고 결정 4가 검증기를 3항목으로 닫아뒀으므로 새 패키지의 경계는 기계 강제를 받을 수 없다. 강제 없는 절단은 모듈만 늘린 것이다. (c)면 검증기 ①(커널의 플랫폼 프레임워크 import 금지)이 파서를 **공짜로** 덮는다.

## 결과와 대가

**얻는 것** — 계약 표면이 한 곳에 닫힌다. `M5`가 재현할 대상이 모듈 하나다. `PhotoSource`는 게임을 모르는 채로 남는다. 파서 경계에 새 검증 항목이 필요 없다.

**포기한 것과 대가** —

1. **커널이 PNG 컨테이너 포맷이라는 게임 밖 지식을 갖는다.** 다른 게임을 지원하려면 커널 안에 추출기가 늘어난다 — 그 확장은 기획이 이미 범위 밖으로 명시했다
2. **압축 `iTXt`가 미래에 나타나면 import 0과 충돌한다.** inflate를 직접 들이든 그 신호를 버리든 새 결정이 필요하다. 표본에서는 16.5개월 22빌드 동안 비압축이었다
3. **파일 바이트가 커널까지 올라온다.** 메모리에 사진 한 장 분량씩 실린다. 순차 처리로 감당하는 것은 구현 몫이다
4. **`0001` 결정 2의 커널 입력 스냅샷("사진 메타값 배열")은 이 문서가 대체한다.** `0001`이 스스로 *"이후의 진실은 `Package.swift`"* 로 열어둔 자리다
