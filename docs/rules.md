# 코드와 주석 규칙

**유일한 잣대다.** 여기 없는 것은 규칙이 아니다 — 기억 속 일반 스타일 가이드를 들고 오지 않는다.

⚠️ **이 문서에 규칙이 생긴 경위를 쓰지 않는다.** 왜 그렇게 정했는지는 `git log`가 진다.
⚠️ **판정이 규칙과 부딪히면 틀린 쪽은 규칙이다.** 예외를 등재하지 말고 규칙을 지우거나 참인 문장으로 다시 쓴다.

---

# 계약 — **기계가 못 막는 셋**

**경계 대부분은 기계가 진다** — 커널 `import` 0 · 어댑터의 쓰기 심볼 · `App`의 사진 프레임워크
`import`는 **검증기가** 막고, 모듈 간선은 **컴파일러가**, 커널 입력 타입은 **`PhotoInput`이**,
장소 경계 재계산은 **`ClassifierTests`가** 진다.

**아래 셋만 기계가 원리적으로 못 본다. 로직을 건드리기 전에 이 셋을 읽는다.**

| | 계약 |
|---|---|
| **1** | **커널 입력값의 「생산 과정」도 계약이다** — 값을 만드는 과정이 플랫폼 프레임워크에 기대면 **그 과정까지 다른 언어 구현이 재현해야 한다.** 그 비용을 물고 채택할지는 알고리즘 결정의 몫이되, **경계는 이 문장으로 지킨다** |
| **2** | **`App`은 자산을 전량 열거해 전부 넘긴다** — 일부만 넘기면 **시간 경계의 불변마저 사라진다.** ⛔️ **커널에 부분 배열을 넘기는 경로를 만들지 마라** |
| **3** | **시각의 출처는 둘이고 순서가 있다** — 파일명이 먼저, 없으면 날짜만. **날짜만 가진 사진은 시간축에 안 놓인다** |

⚠️ **1번이 신호를 더할 때 읽는 문장이다.** 새 값을 커널 입력에 들이려 할 때마다 여기서 값을 매긴다.

**확정된 기술 결정 전체는 기획서 「기술 결정」 절에 있다** — 저장소 밖이다.

# 주석

**주석은 선언을 설명하는 자리다** — 모듈·타입·함수·변수가 무엇이고 무엇을 보장하는가.
**로직을 한국어로 옮기지 않는다.** 코드가 이미 말하는 것은 다시 말하지 않는다.

## 어디에 무엇을 쓰는가

| 층 | 무엇 |
|---|---|
| **파일 머리** `//` | 이 파일이 무엇인가. **5줄 이내** |
| **타입** `///` | 무엇이고 무엇을 보장하는가. 불변식·계약. 길어도 된다 |
| **함수·변수** `///` | **계약이 있을 때만.** 없으면 안 쓴다 |
| **본문** `//` | **구현의 「왜」만.** 왜 이 순서인가 · 왜 이 값인가 · 무엇이 지뢰인가 |

**모듈 문서가 얇은 것도 위반이다** — 총량을 줄이라는 말은 타입 문서를 줄이라는 뜻이 아니다.

### 예외 하나 — 계약을 지는 선언은 타입 문서와 같은 층이다

문법상 함수·변수지만 하는 일이 「모듈·타입」인 자리가 있다. **자격은 셋뿐이다.**

1. **모듈의 입구** — 그 모듈에 들어오는 유일한 문
2. **다른 언어 구현이 재현해야 하는 계약** — 이 저장소에서는 분류 하나뿐이다
3. **등재된 리스크** — `R8` 같은, 문서가 이름으로 든 것

*"중요해서"* 는 자격이 아니다. 자격이 없으면 본문 `//`로 내린다.

## 쓰지 않는 것

1. **로직 번역** — 코드를 한국어로 옮긴 줄
2. **산출물 문서의 사본** — 화면설계서·토큰의 문장을 옮겨 적지 않는다. 값·대비비·자면율·판정 날짜 전부
3. **쓰이는 자리 나열** — grep이 더 정확하다
4. **변경 이력** — git이 진다

## 참조는 「안 죽는 층」만 가리킨다

**가리켜도 되는 것** — 요구사항 ID(`SRC-02`) · 원칙(`P1`~`P5`) · 코드 심볼 · 등재된 리스크(`R8`) · 실험 문서 이름.

⛔️ **산출물 문서의 절 번호를 쓰지 않는다** — 화면설계서·토큰은 개정되고 절 번호가 움직인다.
**화면 ID는 리터럴에 다른 신원이 없을 때만 단다**(`Wording`의 문자열 등).

## 값 표(`Design/`)는 「왜 이 값인가」를 적지 않는다

색과 값을 고른 것은 화면설계의 서사고, 코드는 그 역사를 알 필요가 없다.

**자는 한 줄** — ***코드 안에서 되돌리거나 합쳤을 때 깨지는가.*** 값을 바꿨을 때 깨지는 것은 지뢰가 아니라 설계다.

| 남기는 것 | 안 남기는 것 |
|---|---|
| 「값이 같아도 합치지 마라」 — 역할이 다른 토큰 | 대비비 · 자면율 · 실기기 판정 |
| 플랫폼 지뢰 | 쓰이는 자리 열거 · 판정 서사 |

# 코드

## 타입과 층

- **값은 `struct`, 화면 상태는 `@Observable final class`.** 상속을 설계에 쓰지 않는다
- **프로토콜을 만들지 않는다.** 구현체가 둘 이상 실재할 때만 — 지금 0이다
- **`actor`를 만들지 않는다.** 격리는 `@MainActor`와 값 타입으로 낸다

## 실패 — 세 층

| 층 | 어떻게 |
|---|---|
| **못 일어나는 일** | `precondition` 없이 타입으로 막는다 |
| **바깥이 정할 일** | `throws` — 어댑터가 여기 산다 |
| **정상 갈래** | 옵셔널이나 열거 — 커널은 **안 던진다** |

## 접근 수준 — 계약이 정한다

패키지 밖에서 부를 것만 `public`. **안 쓰는 `public`은 0이어야 한다.**

## 화면

1. **화면 하나 = 파일 하나.** 파일 머리에 화면 ID를 단다
2. **보조 뷰의 집은 쓰는 화면 수가 정한다** — 하나면 그 화면 폴더, 둘 이상이면 `Components/`
3. **화면은 데이터를 만들지 않는다** — 받아서 그린다

## 계약은 공용 조각이 진다

여러 화면이 같은 골격·같은 문자열·같은 규칙을 쓰면 **그것도 조각이다.** 복사하지 않는다.

**언제 뽑는가 — 뜻을 먼저 묻고, 그다음 센다.** 같은 뜻인지 물어 그렇다면 쓰는 곳을 세고, 둘 이상이면 뽑는다. 뜻이 다르면 값이 같아도 안 뽑는다.

## 상태는 누가 갖는가

**그 상태를 쓰는 화면이 하나면 그 화면이, 둘 이상이면 위로 올린다.** 올린 상태를 아래가 직접 쓰지 않는다 — 받아서 그린다.

## 파일의 집 — `App` 층

위에서부터 물어 **처음 걸리는 데서 멈춘다.**

```
0. 쓰는 화면이 하나인가?                         → Screens/<그 화면>/
1. 그 범위에 하나뿐인가 — 진입점·최상위·픽스처      → 범위 루트
2. 값이나 어휘인가 — 그리지 않는다                 → Design/
3. 들고 있는 데이터이거나 그 상태인가              → Data/
4. 화면인가 — 파일 머리에 화면 ID가 있는가          → Screens/
5. 그 밖의 뷰                                    → Components/
```

**폴더는 컴파일러도 검증기도 안 본다 — 찾는 일만 한다.** 화면 폴더는 전용 파일이 생길 때 판다.

## 테스트

- **이름이 요구를 말한다** — `시각을_못_얻은_사진은_unplaced로_빠진다`
- **기대값이 구현의 복사가 아니다.** 구현을 다시 계산해 비교하면 공허하게 통과한다
- **커널은 합성 픽스처로 시험한다** — 개인 사진을 저장소에 넣지 않는다

## 하지 않는 것

1. 이름 없는 유틸 파일 (`Utils` · `Helpers` · `Common` · `Extensions`)
2. 쓰는 곳이 하나인 추상화
3. 모듈을 넘는 공유 — 그건 유틸이 아니라 **경계 결정이라 사용자 판정으로 간다**
4. 미래를 위한 파라미터
5. 커널에 `import`
6. 어댑터 공개 API에 쓰기 연산
7. `App`에서 사진 프레임워크 `import`

## 상한 — 줄 수가 아니라 **표면**

**안 쓰는 `public` 0 · 프로토콜 0 · `actor` 0 · 이름 없는 유틸 파일 0.**
⚠️ **함수 줄 수와 주석 비율은 안 잰다** — 한 표본에서 뽑은 자가 세 번 반증됐다.

# 기계로 보는 넷 — 전부 0이어야 한다

| | 무엇을 막나 | 원문 |
|---|---|---|
| **산출물 문서 절 참조** | 화면설계서·토큰의 절 번호(`§`) — 개정되면 움직인다 | 「참조는 「안 죽는 층」만 가리킨다」 |
| **프로토콜·actor** | 구현체가 하나뿐인데 뚫린 층 | 「타입과 층」 · 「상한」 |
| **커널 `throws`** | 커널이 던지면 실패 세 층이 무너진다 | 「실패 — 세 층」 |
| **이름 없는 유틸 파일** | `Utils` · `Helpers` · `Common` · `Extensions` | 「하지 않는 것」 1 |

**명령은 `apple/scripts/gates.sh`에 있다.** 여기 사본을 두지 않는다 —
자가 두 벌이 되면 한쪽이 낡고 **조용한 0**을 낸다.

**넷 다 grep 한 줄이고 자가 틀릴 여지가 없다.** 이것이 선정 기준이다.

⚠️ **주석 길이를 세는 자를 두지 않는다.** 함수 `///` 3줄 트리아지와 파일 머리 줄 수 검사는
awk가 **네 번 틀렸고**(오탐 둘 · 미탐 둘) 사본이 갈려 조용한 0을 내기까지 했다. **길이는
사람이 위 「예외 하나」의 자격 셋으로 본다** — 기계가 목록을 내도 자격 판정은 어차피 사람 몫이다.
