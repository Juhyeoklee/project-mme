# 코드 규칙

**`M1` 코드 26파일에서 추출했다.** 스타일 가이드가 아니라 이 저장소가 실제로 한 선택이다 —
여기 없는 규칙은 이 코드가 그 선택을 한 적이 없다는 뜻이고, 그때는 구현이 정한다.
⚠️ **지위는 시험 운행이다** — 맨 아래.

주석은 이 문서가 다루지 않는다. `docs/comment-rules.md`가 유일한 잣대다.

## 타입과 층

| 자리 | 규칙 |
|---|---|
| **이름공간** | **case 없는 `enum`.** 인스턴스를 만들 수 없는 것이 요점이다 |
| **데이터** | **`struct` + `Sendable, Hashable`.** `class`는 이유가 있을 때만이고 **그 이유를 타입 문서에 적는다** — 잠금 · `@Observable` · 플랫폼이 클래스만 받는 자리 |
| **주입 이음매** | 둘째 구현체가 **프리뷰·테스트 대역뿐이면 클로저 타입 별칭**, **제품 안에서 둘 다 돌면 프로토콜** |

**둘째 구현체를 세는 것이 판별식이다.** 대역만 있으면 그건 다형성이 아니라 주입이고, 공유
연산이 하나면 시그니처가 곧 계약이다. 아래 칸은 ADR `0001` 결정 5(*어댑터는 조건문이 아니라
구현체 교체*)가 이미 가리킨 자리다.

## 실패

| 층 | 실패를 어떻게 말하는가 |
|---|---|
| **커널** | **값이다** — 옵셔널 · `Result` · 상태 열거형. `throws` 없음 |
| **어댑터** | **`throws`** + 도메인 오류 열거형 하나 |
| **`App`** | 경계에서 받아 **화면 상태로** 바꾼다 |

1. **실패 갈래는 이유를 값으로 갖는다** — 어느 필드인지 · 원문이 무엇인지. **갈래로 못 가르는
   것만** 원문 문자열을 그대로 들고 온다. 추측으로 뭉개지 않는다
2. **실패가 한 종류면 `nil`**, 부르는 쪽이 갈라야 하면 **타입 있는 실패**
3. **플랫폼 오류 → 도메인 오류 번역은 정적 함수 한 자리에 모은다** — 라이브러리 없이
   테스트가 그 함수를 직접 부를 수 있다

## 접근 수준 — 계약이 정한다

**「문서가 그 동작을 못 박았는가」로 가른다. 테스트 가능성은 결과지 이유가 아니다.**

| internal 이상 | `private` |
|---|---|
| 요구(`MOM-*`) · ADR · 리스크(`R8`)가 **동작을 명시한** 것 | 그 밖의 **내부 수단** |
| ⚠️ **지뢰를 지키는 장치** (되돌리면 깨지는 것) | |

`public`은 **패키지 계약**이다 — 쓰는 곳이 생길 때 연다.
타입의 수준은 **자기를 쓰는 함수를 따라간다**(고르는 것이 아니라 강제다).

## 화면

1. **화면 하나 = 파일 하나.** 파일 머리에 화면 ID
2. **보조 뷰의 집은 쓰는 화면 수가 정한다** — 여럿이 쓰면 자기 파일, **한 화면만 쓰면 그 화면
   파일 아래 `private`으로.** 밖에서 쓸 일이 생기면 그때 파일을 옮긴다
3. **`body`는 조립만 한다.** 조건·계산은 `private var`·`private func`로 뺀다
4. **값은 3단** — ① 두 곳 이상에서 **같은 뜻**이면 토큰 ② 한 곳이면 **이름 있는 상수·변수**
   ③ 이름으로 안 되면 한 줄 근거. ⚠️ **값이 같아도 하는 일이 다르면 묶지 않는다**

## 테스트

1. **파일은 `// MARK:` 절로 갈리고 마지막 절이 「계약」이다** — 그 모듈이 지켜야 할 불변을
   거기 모은다. 기능 테스트와 섞지 않는다
2. **픽스처는 경로를 실제로 태운다** — 기대 구조를 손으로 적지 않는다. 손으로 적으면 코드가
   틀려도 테스트가 같이 틀린다
3. 표 케이스는 **`@Test(arguments:)`**. 첫 원소를 케이스 이름으로 두면 실패가 무엇이
   깨졌는지 말한다
4. 옵셔널은 **`throws` 테스트 + `try #require`.** ⚠️ **`try!`를 쓰지 않는다** — 터지면
   줄 번호만 남고 이유가 안 남는다
5. **임계값을 하드코딩하지 않는다** — 설정에서 파생시킨다. 값이 바뀌면 테스트가 조용히
   다른 것을 검사하게 된다
6. 이름은 한국어 서술문 (`docs/comment-rules.md` 「그 밖」 5)
7. ⚠️ **뷰 소속 계산을 시험하는 스위트는 `@MainActor`다** — `View`의 격리를 물려받으므로.
   빼면 **컴파일은 통과하고 실행 중에 격리 검사가 트랩을 낸다**(2026-08-10 실측)

## 형식

**`// MARK:`의 하이픈이 계층을 진다** — `// MARK: - 큰 절` / `// MARK: 작은 절`.

## 하지 않는 것

1. **미리 층을 만들지 않는다** — 프로토콜 · 제네릭 · actor. 위 판별식이 아래 칸을 가리키기
   전까지는 구현 시점에 판단한다
2. **안 쓰는 `public`을 만들지 않는다** — 남아 있으면 다음 세션이 *"이미 있으니 이걸 쓰자"* 로
   반쪽 API에 화면을 맞춘다
3. **이름 없는 집을 만들지 않는다** — `Utils` · `Helpers` · `Common`. 공유물의 집은
   **역할 이름**을 갖는다. 이름이 없으면 뭐든 빨아들인다
4. ★ **모듈을 넘어 공유하지 않는다.** 넘어야 하면 그건 유틸이 아니라 **경계 결정**이고
   ADR로 간다 (`M1` 실측: PNG 합성기가 커널 테스트와 `App` 프리뷰에 두 벌 있다.
   **30줄 중복이 모듈 하나보다 싸다** — ADR `0001` 결정 1)
5. **이유 없는 `class`를 쓰지 않는다**
6. **커널에 `throws`를 들이지 않는다** — 다른 언어 구현이 재현할 계약에 예외 흐름을 넣지 않는다
7. **뷰에서 색·글꼴·간격을 발명하지 않는다**
8. **`Date`·`Calendar`를 커널과 문구에 쓰지 않는다** — 표시하려고 시간대를 발명하면 자정
   근처에서 날짜가 밀린다

## 상한 — 줄 수가 아니다

⚠️ **줄 수 상한은 안 건다.** 「함수 40줄」을 걸면 걸리는 셋이 `averageLinkageClusters`(56 ·
알고리즘 한 덩어리) · `PNGText.scan`(50 · 청크 루프) · `laterPasses`(46 · 순차 패스)이고
**셋 다 쪼개면 더 나빠진다.** 주석 규칙이 비율 상한에서 겪은 것과 같은 반증이다 —
가장 정당한 코드가 먼저 걸리는 상한은 오탐이 신호를 죽인다.

상한은 **표면과 층**에 건다. 이 코드가 실제로 자라는 방향이 거기다.

| | |
|---|---|
| 안 쓰는 `public` | **0** |
| 프로토콜 · actor | **0** — 판별식이 아래 칸을 가리키기 전까지 |
| 이름 없는 유틸 파일 | **0** |
| 이유 없는 `class` | **0** |
| 파일당 최상위 타입 | **주 타입 1 + 그 파일 전용 보조.** 예외는 **값 모음 파일**뿐 |

## 기계로 보는 셋

`precommit-review` 2단계가 돌린다. 전부 0이어야 한다.

```
cd apple
grep -rnE '^ *(public )?(protocol|actor) ' --include='*.swift' --exclude-dir=.build .
grep -rn 'throws' Packages/MomentKernel/Sources
find . -name 'Utils.swift' -o -name 'Helpers.swift' -o -name 'Common.swift' \
       -o -name 'Extensions.swift'
```

⚠️ **「안 쓰는 `public`」은 grep 한 줄로 안 된다** — 심볼을 뽑아 자기 파일 밖 사용을 세야 한다.
스크립트를 들일지는 따로 판정할 자리고, 그때까지는 사람 층이 본다.

## 지위 — 시험 운행

⚠️ **`M1`에서 추출한 규칙은 `M1` 코드로 검증할 수 없다.** 표본이 전부 추출 원본이라
100% 준수가 당연하고, **그 숫자는 아무것도 말하지 않는다.**

첫 표본은 `M2` 구현이다. 거기서 나온 반증이 이 문서를 고친다 — 특히 **저장 실패**가
위 실패 3층을 시험한다. 저장은 커널도 어댑터도 아닌 `App` 안이라(ADR `0001` 대가 3)
지금 표에 자리가 없다.
